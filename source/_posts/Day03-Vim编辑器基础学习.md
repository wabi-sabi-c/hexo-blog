# Day03｜Vim 编辑器零基础

今天是 180 天运维自学计划第 3 天，学习 Linux 必备工具：**Vim 编辑器**。
新手最容易卡在“进得去、出不来”，这篇只教最实用的，保证你学得会、用得顺。

## 一、Vim 三种模式（必懂）
- **命令模式**：刚打开文件时的状态，可移动光标、复制、删除
- **编辑模式**：按 `i` 进入，可输入文字
- **末行模式**：按 `:` 进入，可保存、退出
<!-- more -->

## 二、最核心 6 个操作（背会就能用）
1. 打开文件
```bash
vim test.txt
```
2. 进入编辑模式
```bash
i  # 在光标前插入
```
3. 保存并退出编辑模式
```bash
：wq
```
4. 不保存强制退出编辑模式
```bash
：q!
```
5. 放弃修改回到命令模式
```bash 
Esc
```
6. 显示行号（运维常用）
```bash
:set number     # 显示行号(简写nu)      
:set nonumber   # 取消行号(简写nonu)      
```

## 三、高频实用命令
- 复制当前行：`yy`
- 删除当前行：`dd`
- 粘贴当前行：`p`
- 撤销：`u`
- 光标跳到文件首行：`gg`
- 光标跳到文件尾行：`G`

## 四、新手实战
```bash
# 1. 创建并打开文件
vim test.txt
# 2. 进入编辑模式按键 i 输入：
Hello World
Hello Vim
12345
# 3. 按下 Esc 键回到命令模式
# 4. 输入命令 `:wq` 保存并退出
# 5.查看文件
cat test.txt
# 6. 输入命令 `:set number` 显示行号
# 7. 打开文件
vim test.txt
# 8. 随便乱按，然后Esc 输入命令 `:q!` 强制退出
```
