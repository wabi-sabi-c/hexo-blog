# React简介


**React 18** 是目前最流行的 **前端 JavaScript 库**，用于构建用户界面（UI）。

在你的 ToDo-App 项目中，它扮演着 **“页面建筑师”** 和 **“交互管家”** 的角色，负责你在浏览器中看到的所有内容。

<!--more-->


### 1. 核心作用


*   **构建 UI 组件**：React 允许你将页面拆分成独立的、可复用的“组件”（Components）。例如，你的项目中可能有 `<TaskList />`（任务列表）、`<TaskItem />`（单个任务项）、`<AddTaskForm />`（添加任务表单）等组件。
*   **管理状态 (State)**：当你在输入框打字或勾选复选框时，React 会追踪这些数据的变化（即“状态”），并自动更新页面显示，无需你手动操作 DOM。
*   **与后端通信**：React 负责发送网络请求（通常使用 `fetch` 或 `axios`）给 **FastAPI** 后端，获取任务列表或提交新任务，并将返回的数据展示在页面上。


### 2. 为什么选择 React 18？


*   **组件化开发**：代码结构清晰，易于维护和扩展。比如你想修改任务项的样式，只需修改 `<TaskItem />` 组件，所有地方的任务项都会同步更新。
*   **虚拟 DOM (Virtual DOM)**：React 会在内存中维护一个虚拟的页面结构。当数据变化时，它会对比前后差异，只更新页面上真正变化的部分，而不是刷新整个页面，从而提供流畅的用户体验。
*   **版本 18 的新特性**：
    *   **并发渲染 (Concurrent Rendering)**：这是 React 18 的核心升级。它允许 React 同时准备多个版本的 UI，优先处理紧急更新（如用户输入），延后处理不紧急的更新（如列表过滤），使应用响应更灵敏。
    *   **自动批处理 (Automatic Batching)**：将多个状态更新合并为一次渲染，进一步提升了性能。


### 3. 在项目中的工作流程


1.  **用户操作**：你在页面上点击“新建任务”按钮。
2.  **React 响应**：捕获点击事件，更新本地状态（如显示输入框）。
3.  **发送请求**：当你提交表单时，React 调用 API 接口，将数据发送给 **FastAPI**。
4.  **接收反馈**：FastAPI 处理完毕并返回成功信号后，React 更新状态，将新任务添加到列表中，页面随即自动刷新显示新任务。


### 4. 总结它在项目中的位置


*   **PostgreSQL**：存数据的 **仓库**。
*   **FastAPI**：处理逻辑的 **后端服务器**。
*   **React 18**：展示数据并与用户互动的 **前端界面**。

简单来说，**React 18 决定了你的 ToDo 应用“长什么样”以及“如何响应用户的操作”**。它是用户直接接触到的那一层。
