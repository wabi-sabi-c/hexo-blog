换新电脑必备环境
1.  Git（必装）
2.  Node.js 16/18/20 都行（推荐 18）
3. 不需要先装 hexo！新电脑不需要全局安装！

1. hexo d 去哪里 → 看 _config.yml 文件
2. git push 去哪里 → 看 .git/config 文件（你克隆的地址）

1. 打开你博客根目录的 _config.yml，拉到最下面，你会看到 deploy 配置：
deploy:
  type: git
  repo: https://github.com/用户名/目标仓库.github.io.git  # 👈 就是这里！
  branch: main

2. git push 怎么知道推去 hexo-blog  因为你克隆的就是 hexo-blog 仓库
你当初克隆源码仓库时，用的命令是：
git clone https://github.com/用户名/目标仓库.git
Git 会自动记住：
这个文件夹 绑定的远程仓库就是 hexo-blog
你可以输入这条命令查看当前仓库绑定的地址：
git remote -v


步骤 1：克隆你的「源码仓库」
注意：克隆的是存源码的那个仓库，不是 github.io！
git clone https://github.com/你的用户名/hexo-blog.git
cd hexo-blog

步骤 2：安装依赖（自动复原一模一样环境）
npm install
不需要手动装 hexo！自动全部装好。

步骤 3：测试是否正常
hexo -v
出现版本号 = 成功！
步骤 4：直接写文章 + 部署


git pull 会把github仓库里新文件同步到本地
